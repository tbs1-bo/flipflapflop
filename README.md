# flipflapflop
Steuerung einer Flipdot-Zielanzeige mit verschiedenen Mikrocontrollern.

Die Dokumentation befindet sich unter https://tbs1-bo.github.io/flipflapflop/

Die Demos lassen sich ganz ohne Installation direkt im Browser auf einer
virtuellen Flipdot-Anzeige ausprobieren:
https://tbs1-bo.github.io/flipflapflop/webdemo/ (Quelle: [webdemo/](webdemo/)).
  
Ein ähnliches Projekt zur Ansteuerung von LED-Anzeigen ist unter
[BoLED](https://github.com/tbs1-bo/BoLED) zu finden.
